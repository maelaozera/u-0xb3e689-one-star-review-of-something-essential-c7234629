Entry for the make.fun bounty [One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

A deterministic Node 22 program that writes one deadpan one-star review of
gravity — 118 characters, well within the 160-character gate — to
`/output/entry.txt`:

> One star. Drops everything I own without warning, holds nothing up, and has never once apologised for my phone screen.

Run it with:

```sh
node main.ts
```

It honours `MAKEFUN_OUTPUT_DIR` when set, otherwise writes to `/output`.
